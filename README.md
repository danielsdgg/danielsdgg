### FORT Ministry Platform
*A membership, events and payments system for Life Church International, Limuru.*

| | |
|---|---|
| **Problem** | Members, small groups, events, registrations and payments were managed manually across spreadsheets. |
| **Solution** | A Flask JSON API with a Next.js (App Router) + TypeScript + Tailwind frontend, an admin dashboard, and a public site with a database-driven events calendar. |
| **Highlights** | A single `people` model with typed members and friends, separate registration, payment, attendance and feedback tables, QR check-in with non-guessable public tokens, a bulk importer that cleans messy Excel lists, and httpOnly-cookie JWT admin auth with CSRF protection. |
| **Stack** | Python · Flask · Flask-JWT-Extended · Next.js · TypeScript · Tailwind CSS |
